Tesla Powerpack

A live energy overview in Apple Home. Local telemetry, a dashboard camera, and optional MQTT export.

Controller credentials

Choose the PEM CA certificate and token supplied by Tesla. They are stored privately on your Homebridge host; the configuration keeps only their file paths.

Extensionless files are supported. Upload both files when replacing credentials. Nothing is uploaded to the Powerpack.

Set the controller address and MQTT options below, then Save and restart the child bridge. For a new installation, use the plugin menu’s Set Up Child Bridge option and pair its camera and sensors in Apple Home.
