First release of **`@wcoekaer/homebridge-tesla-powerpack`**.

- Local, authenticated Powerpack telemetry over seven allowlisted HTTPS GET endpoints. TLS verification stays enabled; no controller writes, POSTs, or configuration operations.
- A 1080p HomeKit dashboard camera with a Powerpack cabinet cutaway, pod/inverter counts, energy and power readings, electrical measurements, alerts, and local history.
- Native HomeKit battery percentage and charging state, plus charging/discharging and configurable battery-level threshold contacts for automations.
- Homebridge setup UI with PEM CA and bearer-token uploads, controller hostname/IP settings, and a GET-only connection test. Uploaded credentials stay in Homebridge storage and are never bundled.
- Optional publish-only MQTT export of normalized and full raw telemetry, with timestamps, freshness, retained messages, and availability.
- Stale-data handling, child-bridge support, and stable accessory cache restoration.

### Install

Download **`wcoekaer-homebridge-tesla-powerpack-0.1.0.tgz`** from this release and install it in the Node environment running Homebridge:

```sh
npm install -g /absolute/path/wcoekaer-homebridge-tesla-powerpack-0.1.0.tgz
```

Restart Homebridge, open the plugin's settings, upload your Tesla-issued certificate and token, enter the controller address, and use **Set Up Child Bridge**. Pair its camera and sensors in Apple Home.

`SHA256SUMS` verifies the release archive. No site credentials are included. This GitHub release does not publish the package to the npm registry.

### Requirements and verification

Homebridge 1.8+ / 2.x and Node 22.12+, 24, or 26. Live camera streaming requires FFmpeg with libx264 and SRTP; snapshots and sensors do not. The optional FFmpeg package or a system installation can provide it.

The release workflow runs the automated test suite and a real disposable Homebridge child-bridge smoke test. Verification covers TLS/GET-only access, uploads, MQTT, battery automations, cache restoration, and encrypted video decoding. Local GET telemetry and rendering were also verified against a real Powerpack controller. Apple Home pairing and remote playback still need verification on the target installation.

Pod/inverter graphics are schematic and show aggregate counts, not unavailable per-pod cell measurements. The camera is a live dashboard, without HomeKit Secure Video recording.
